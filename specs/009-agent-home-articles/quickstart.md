# Acceptance Quickstart

1. Open Agent with an account that has historical conversations. Confirm no history is visible.
2. Send an article query. Confirm a new conversation appears only after sending.
3. Confirm each returned article has a card and opens its own detail page in one click.
4. Return to Agent and send a follow-up. Confirm only the current session is displayed.
5. Test a no-result query and confirm no empty card area or raw JSON appears.
